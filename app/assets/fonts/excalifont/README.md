# Excalifont

Excalidraw's hand-drawn typeface, used for the labels in figures (`SketchFigure`).
This is the Latin subset shipped in `@excalidraw/excalidraw` 0.18.1
(`dist/prod/fonts/Excalifont/`), renamed. The unicode range in `main.css` is the
one Excalidraw declares for this file.
